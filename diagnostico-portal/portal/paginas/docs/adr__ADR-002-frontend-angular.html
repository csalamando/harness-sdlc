Paso 1: Problem Statement

La PoC en JavaScript plano validó el modelo y la UX, pero no es mantenible como producto: sin tipado, sin estructura por módulos y sin estándar de build, cada cambio es riesgoso y el equipo no puede aplicar los estándares corporativos de desarrollo front.

Paso 7: Decisión

Decisión Adoptada

Angular v17+ standalone con Signals, MSAL, lazy loading por catálogo y tokens de diseño gobernados.

Razones Principales

  • Es el estándar corporativo vigente
  • Tipado fuerte del modelo en compilación
  • Ecosistema de testing y build alineado con CI/CD

Consecuencias Positivas Esperadas

  • Errores de modelo detectados en compilación
  • Cadena de build estándar integrable al pipeline

Consecuencias Negativas Aceptadas

  • Reescritura completa de la PoC (esfuerzo no recuperable)
  • Dependencia de la cadena Node en CI/CD

Qué NO se Decidió

  • React: fuera del estándar corporativo
  • Mantener la PoC vanilla: no apta para producto
